# Build Record

_Required by PRD §13: what was generated by tooling, and what was done by hand._

**No code generator was used.** Every file in this repository was written by hand with an LLM coding assistant in session, reviewed by the owner through the `docs/design-review.md` decisions. Reference patterns (read and adapted, not copied) came from a private set of LangGraph example projects: a durable-operations workflow (checkpointing, budget gate, resumable terminal states), a docs-RAG graph (retrieval node shape), a fan-out policy (reserve-before-send paid-call gating and ledger states), and a typed runtime-events contract.

**Design refinements discovered during Phase 4 evaluation** (recorded in `design-review.md` as implementation notes):
- A `requires` value now also counts toward context match; previously an on-topic EU-only template lost to an off-topic tier-matching one.
- Semantic similarity is min-max normalized across the retrieved set (raw kept as `semantic_raw`); raw cosine gaps were too narrow for the semantic component to hold its weight against context.
- The preference back-off no longer falls through to the global key when the form has any context; the first report showed selections in one context leaking into an unrelated sparse one.

Subsequent manual changes after this record: none.
